## JFrame

JFrame is a top-level window in Java Swing. It provides the main window in which GUI components such as buttons, panels, labels, and custom graphics can be placed.

### Common Uses

* Creates the application window.
* Sets the window size.
* Sets the title.
* Controls what happens when the window is closed.
* Allows components such as `JPanel` to be added.

### Example

java
JFrame frame = new JFrame("My Application");

frame.setSize(600, 400);
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setVisible(true);


---

## JPanel

JPanel is a container component in Swing. It is mainly used to organize and hold other GUI components.

It can also be used as a drawing area by overriding its paintComponent() method.

### Example

java
JPanel panel = new JPanel();

frame.add(panel);


A custom panel can be created by extending JPanel:

java
class MyPanel extends JPanel {
    // Custom functionality
}


---

## Paint Component

paintComponent(Graphics g) is a method of JPanel that is used for custom drawing.

When we want to draw shapes, lines, text, etc. on a panel, we override this method.

### Example

java
class MyPanel extends JPanel {

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);

        g.drawRect(50, 50, 100, 80);
    }
}


### Important Point

Always call:

java
super.paintComponent(g);


at the beginning of the overridden method so that the panel is properly cleared and painted before our custom drawing.

## Graphics

Graphics is a Java class used for drawing on components.

It provides methods to draw:

* Lines
* Rectangles
* Circles/Ovals
* Text
* Polygons
* Other shapes

Example:

java
g.drawLine(10, 10, 100, 100);
g.drawRect(50, 50, 100, 80);
g.drawOval(100, 100, 80, 80);
g.drawString("Hello", 50, 50);


The Graphics object is normally provided automatically to the paintComponent() method.

## 5. Understanding `g.drawRect()`

The method:

java
g.drawRect(x, y, width, height);


takes **four values**.

These four values represent:

1. x → X-coordinate of the **top-left corner**
2. y → Y-coordinate of the **top-left corner**
4. width → Width of the rectangle
5. height → Height of the rectangle

### Important Concept

The first two values:

text
x, y

represent **one coordinate point** — the top-left corner.

The other two values:

text
width, height


define the size of the rectangle.

So:

java
g.drawRect(50, 30, 200, 100);

means:

text
Starting point = (50, 30)
Width          = 200
Height         = 100


It does not mean four coordinate points.

## Coordinate System in Java Graphics

Java GUI coordinates start from the top-left corner of the component.

text
(0,0) ---------------------> X
  |
  |
  |
  |
  v
  Y


Therefore:

* Moving right → increases x
* Moving left → decreases x
* Moving down → increases y
* Moving up → decreases y

For example:

java
g.drawRect(50, 50, 100, 80);


starts the rectangle at (50, 50).

## Classes in Java

A class is a blueprint or template used to create objects.

A class can contain:

* Variables
* Methods
* Constructors
* Objects
* Other logic

### Basic Class Structure

java
class Student {

    String name;
    int age;

    void display() {
        System.out.println(name);
    }
}


Here:

* Student → class
* name and age → variables/fields
* display() → method

### Creating an Object

An object is created using the new keyword:

java
Student s1 = new Student();


Here:

* Student → class/type
* s1 → object reference
* new Student() → creates an object of the class

## How Classes Are Used with JFrame and JPanel

A common Java Swing application structure is:

text
Main Class
    |
    v
JFrame
    |
    v
JPanel
    |
    v
paintComponent()
    |
    v
Graphics
    |
    v
Draw Shapes / Text


For example:

java
import javax.swing.*;
import java.awt.*;

class MyPanel extends JPanel {

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);

        g.drawRect(50, 50, 100, 80);
    }
}

public class Main {

    public static void main(String[] args) {

        JFrame frame = new JFrame("Graphics Example");

        MyPanel panel = new MyPanel();

        frame.add(panel);
        frame.setSize(500, 400);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);
    }
}


### Flow of the Program

1. Main starts the application.
2. A JFrame is created.
3. A custom JPanel is created.
4. The panel is added to the frame.
5. The frame becomes visible.
6. Swing calls paintComponent().
7. The Graphics object is used to draw the rectangle.

## What is a Framework?

A framework is a pre-built structure that provides tools, classes, and rules for developing applications.

Instead of creating everything from scratch, developers use the framework's existing functionality.

### Examples

* Swing → Java GUI development
* Spring → Java backend/web applications
* React → User interface development
* Django → Python web development

A framework provides a structure that helps developers build applications faster and in an organized way.

## 10. Maven

It helps with:

* Managing dependencies
* Compiling Java code
* Running tests
* Building projects
* Managing project structure
* Packaging applications

text
