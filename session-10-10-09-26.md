## 1. Streaming vs Files

In class, we discussed the difference between files and streams.

A **file** is a collection of data stored permanently and generally has a definite size. We can read from or write to a file whenever required.

A **stream** represents a continuous flow of data. Unlike a file, a stream does not necessarily have a fixed size and can be endless. For example, live video, audio, or data received from a network can be considered streams.

The main difference is that files usually represent stored data, while streams represent data flowing from one place to another.

## 2. Extracting Substreams and Concatenating Streams

We also discussed how streams can be divided and combined.

- **Extracting substreams:** A substream is a smaller portion of a larger stream. Extracting a substream allows us to work with only a specific part of the data.
- **Concatenating streams:** Concatenation means joining two or more streams together to form a single continuous stream.

These operations are useful when processing large amounts of data, combining files, or handling data received from different sources.

## 3. XML and Its Main Purpose

XML stands for **Extensible Markup Language**.

The main purpose of XML is to **store, organize, and transport structured data** in a format that both humans and computers can understand.

XML uses custom tags to describe the meaning of data. For example:

```xml
<student>
    <name>Kunjal</name>
    <course>CSE</course>
</student>
```

## 4. How Networking Is Useful for Graphics

Networking allows graphics applications to communicate and share visual information between different computers.

For example, networking can be used in:

Multiplayer games, where players share their actions and game states.
Online drawing applications, where multiple users can draw on the same canvas.
Video conferencing, where images and video are transmitted over a network.
Remote desktop applications, where the screen of one computer is displayed on another.

Thus, networking makes it possible to create interactive graphics applications that work across multiple devices.

## 5. Database vs Graphics

We discussed the difference between databases and graphics and how they can work together.

A database is used to store, organize, and retrieve data. It focuses on managing information efficiently.

Graphics are used to represent information visually through images, shapes, charts, animations, and user interfaces.

For example, a student management application may store student marks in a database and use graphics to display those marks in the form of charts.

The database manages the actual data, while graphics help users understand and interact with that data.
